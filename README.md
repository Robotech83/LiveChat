# 💬 LiveChat — Vanilla JavaScript Chat Interface

A lightweight, browser-based chat interface built with **vanilla JavaScript**, HTML, and CSS.  
This project demonstrates real-time UI updates, event-driven logic, and clean DOM manipulation **without frameworks**.

🚧 **Status:** This project is still under construction.

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://robotech83.github.io/LiveChat/)

---

## 📌 Project Goals

This project was built to:
- Practice **pure JavaScript** (no React, no libraries)
- Demonstrate **event-driven UI logic**
- Explore **real-time interaction patterns**
- Build a clean, readable front-end codebase

---

## 🧠 What This Project Demonstrates

- **Vanilla JavaScript fundamentals**
  - DOM selection & manipulation
  - Event listeners
  - Dynamic element creation
- **Real-time UI behavior**
  - Messages appear instantly
  - Input handling and state updates
- **Clean separation of concerns**
  - HTML structure
  - CSS styling
  - JavaScript logic
- **Framework-free design**
  - No React
  - No external JS libraries

---

## 🛠 Technologies Used

- HTML5
- CSS3
- **JavaScript (ES6+)**
- GitHub Pages (deployment)
